# SQL Query Conventions

Generated by sqlc. Source `.sql` files live here; generated Go code goes to `../gen/`.

## Naming

### Prefixes

| Prefix | Use | sqlc type |
|--------|-----|-----------|
| `Get` | Single row by ID or unique key | `:one` |
| `List` | Multiple rows | `:many` |
| `Count` | Aggregate returning a single integer | `:one` |
| `Insert` | Create a row | `:exec` |
| `Update` | Modify a row | `:exec` |
| `Delete` | Remove a row | `:exec` |
| `Set` | Toggle or assign a single field | `:exec` |

### Suffixes

Encode scope and sort order into the name so there's no hidden behavior:

- **Scope**: `ByCategory`, `ByAccount`, `ByConversation` — filters the result set.
- **Sort**: `ByCost`, `ByCreatedAsc`, `ByPendingCount` — declares the `ORDER BY`.

Sort suffixes come last. If a query has an `ORDER BY`, the name must say so.

```
List<Entity>[By<Filter>][By<Sort>]
```

Examples:
- `ListMessagesByConversationByCreatedAsc` — filtered by conversation, sorted by created_at ascending
- `ListWasteCategoryStatusesByCost` — all waste categories, sorted by cost descending
- `ListTopPendingPoliciesByCategoryByCost` — filtered by category, sorted by cost, with LIMIT
- `ListServices` — no filter, no meaningful sort (or alphabetical by default)

When the sort direction is obvious from context (cost = descending, name = ascending), omit `Asc`/`Desc`. Include it when it's ambiguous.

## Ordering

Every `ORDER BY` in SQL is encoded in the query name. This makes ordering explicit and discoverable.

When a caller needs a different sort on the same data:
- **Query uses `LIMIT`**: Add a new named query — the DB must sort before truncating.
- **Query returns a small set** (categories, services — tens of rows): Re-sort in Go with `slices.SortFunc`. No new query needed.

### Go-side re-sorting

When a caller needs a different order on a small result set, sort in the Go wrapper (not `gen/`):

```go
slices.SortFunc(result, domain.PolicyCategoryStatusByCostDesc)
```

Define sort functions on the domain type so they're reusable:

```go
// In domain/policy_category_status.go
func PolicyCategoryStatusByCostDesc(a, b PolicyCategoryStatus) int { ... }
```

## Other conventions

- Use `COALESCE` for nullable text columns to avoid `*string` in Go.
- Use `CAST(COALESCE(..., 0) AS INTEGER)` for nullable integer columns.
- Leave nullable floats as-is (`*float64`) — callers need to distinguish "no data" from zero.
- Use `?1`, `?2` positional params (or `sqlc.arg('name')` for clarity).
- One file per table or logical group.
